# Earthquake Data Analysis (Python 3.9)

A seismic data analysis project developed using **Python 3.9** for processing, analyzing, and interpreting earthquake datasets.  
This project focuses on extracting meaningful insights from seismic activity data through statistical analysis and visualization.

---

## 🐍 Python Version

This project is developed and tested using:

**Python 3.9**

Make sure Python 3.9 is installed before running the project to ensure compatibility.

---

## 📌 Overview

This project performs comprehensive earthquake data analysis, including:

- Data loading and preprocessing
- Cleaning and filtering seismic records
- Magnitude-based analysis
- Time-series earthquake trend analysis
- Location-based insights
- Statistical summaries
- Data visualization

The project is suitable for:

- Academic research
- Data science practice
- Seismology studies
- Python data analysis learning

---

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone <repository-url>
cd earthquake-data-analysis-python-3.9
```

### 2️⃣ Create a Virtual Environment (Recommended)

```bash
python -m venv venv
venv\Scripts\activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

If `requirements.txt` is not available, install manually:

```bash
pip install pandas numpy matplotlib seaborn
```

---

## ▶️ Running the Project

Execute the main script:

```bash
python main.py
```
